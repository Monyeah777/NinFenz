## 一、判级器（RFC2119/8174 NF 化 · 落档 06 §11.1）

| 强度词 | 级别 | 违反判定 |
|---|---|---|
| 必须 / 禁止 / 不得 | 硬约束 | 结构事故：回滚 + 记失范；演练 = 硬断言 FAIL |
| 应 | 默认行为 | WARN + 可说明性豁免；演练 = 软断言 WARN |
| 可 | 自由区 | 无判定；自由区不得上硬断言 |

判级语义与 verify 判定 / M1 演练断言分级一一对应；未标强度词条款按「可」处理（防把资料当指令）。
