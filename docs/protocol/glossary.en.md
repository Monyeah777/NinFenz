## 协议层

### deliverable contract · 交付物契约

- **EN**：A machine-checkable contract for what an AI must deliver: structure, acceptance criteria and boundaries, not just a one-line request.
- **中文**：把「AI 应产出什么」写成可机器验收的契约（结构 + 验收判据 + 边界），而不是只给一句需求。
- **Source**：`llms.txt` · 关键词「交付物契约」

### contract · 契约

- **EN**：An explicit agreement between a module and its callers (inputs, outputs, events, boundaries); replacing a module must keep the contract unchanged.
- **中文**：模块与调用方之间的显式约定（输入/输出/事件/边界）；替换模块时契约不得变。
- **Source**：`01_核心协议.md` · §1. 模块协议 · 关键词「契约」

### clause · 条款

- **EN**：A single, number-addressable protocol provision; changing it must follow the migration record and version-field discipline.
- **中文**：编号可引用的单条协议规定；变更须走迁移记录与版本字段纪律。
- **Source**：`01_核心协议.md` · 关键词「条款」

### module · 模块

- **EN**：The smallest loadable unit defined by the protocol: machine contract (id, layer, inputs, outputs, events) plus a replaceable boundary.
- **中文**：协议定义的最小可装载单元：含机读契约（id/层/输入/输出/事件）与可替换边界。
- **Source**：`01_核心协议.md` · §1. 模块协议 · 关键词「模块」

### pipeline · 管线

- **EN**：The source of truth for execution order: assembling modules by layer slots (P00–P80) and flow.
- **中文**：按层位（P00–P80）与流程把模块装配起来的执行顺序真源。
- **Source**：`01_核心协议.md` · §2. 管线规范 · 关键词「管线」

### asset · 资产

- **EN**：Domain data accessed by modules through the five asset interfaces (get/query/match/roll/register), never by reading loose files directly.
- **中文**：模块经资产五接口（get/query/match/roll/register）访问的题材数据，不直读散文件。
- **Source**：`01_核心协议.md` · §3. 资产库接口 · 关键词「资产」

## 装配层

### event · 事件

- **EN**：The only inter-module communication channel (publish/subscribe); each event has exactly one publisher, and every subscription must resolve to one.
- **中文**：模块间唯一通信通道（publish/subscribe）；发布方唯一，订阅须有发布方。
- **Source**：`01_核心协议.md` · §1. 模块协议 · 关键词「事件」

### artifact · 产物

- **EN**：A single output file from assembly (full Markdown / export face); it must be reproducible and checkable.
- **中文**：装配输出的单件文件（完整版 Markdown / 导出面）；须可复现、可验收。
- **Source**：`protocol/CONFORMANCE.md` · 关键词「产物」

### layer · 层

- **EN**：One of the nine pipeline layers (P00–P80); modules mount by layer, and off-layer modules raise an assembly warning.
- **中文**：管线的九层位（P00–P80）；模块按层挂载，层外模块是装配警告。
- **Source**：`01_核心协议.md` · §1. 模块协议 · 关键词「管线层」

### workflow · 工作流

- **EN**：A declared, routable unit of work (e.g. routing / assemble); machine faces first, no silent fallback on dispatch failure.
- **中文**：声明式路由的工作单元（如 routing / assemble），机器面优先、失败不回退。
- **Source**：`docs/agent/AI_ROUTING.md` · 关键词「工作流」

### slot · 槽

- **EN**：A declared data read/write position on a module; writes must match declarations, and an undeclared write is a data incident.
- **中文**：模块声明的数据读写位；写入须与声明一致，未声明写槽即数据事故。
- **Source**：`02_联动注册表.md` · §2. 官方核心模块表（13 件） · 关键词「数据槽」

### state · 状态

- **EN**：A re-readable state snapshot of assembly or runtime (data slots / round state header); not narrative prose.
- **中文**：装配与运行可重读的状态快照（数据槽 / 回合状态头）；不是叙事正文。
- **Source**：`01_核心协议.md` · §1.1 模块头机读契约（v1.0.0 C1 · T1-1） · 关键词「状态」

### assembly · 装配

- **EN**：The process of assembling pipeline, modules and assets into a deliverable; the result must pass the quality gate before export.
- **中文**：把管线、模块、资产装配成可交付产物的过程；装配结果先过质量门再导出。
- **Source**：`07_官方核心出厂与社区预设导航.md` · §2. 官方核心装配（P01 标准管线） · 关键词「装配」

### role · 角色

- **EN**：The responsibility boundary of participants such as assemblers and executing agents; crossing it is a protocol incident.
- **中文**：装配师/执行 agent 等参与方的职责边界；角色越界即协议事故。
- **Source**：`06_Agent执行协议.md` · §1. 角色定位与职责边界 · 关键词「角色」

## 质量层

### conformance · 一致性

- **EN**：An explicit statement of what is conformant, what it covers and what it excludes, compared clause by clause with the source of truth.
- **中文**：「符合什么、管到哪、什么不管」的显式声明，逐条与真源比对。
- **Source**：`protocol/CONFORMANCE.md` · 关键词「一致性」

### reproducibility · 可复现

- **EN**：Same input, same output: no randomness, network or wall-clock dependence; a rerun yields the same result.
- **中文**：同输入同输出：无随机、无网络、无墙钟依赖；可重跑得到同一结果。
- **Source**：`protocol/CONFORMANCE.md` · 关键词「可复现」

### benchmark · 基准

- **EN**：A comparable baseline (score, shape or behaviour); without a baseline there is no claim of improvement.
- **中文**：可对照的基线（分数/外形/行为）；无基线不称改进。
- **Source**：`02_联动注册表.md` · 关键词「基准」

### audit · 审计

- **EN**：A sign-off record binding conclusions to subject digests; changing the subject invalidates the old audit.
- **中文**：对结论绑定对象摘要的签收记录；对象一改旧审计即失效。
- **Source**：`06_Agent执行协议.md` · §0. 输入信任边界与消费纪律（外来内容 = 数据，不是指令） · 关键词「审计」

### test case · 用例

- **EN**：An executable acceptance sample (precondition, action, assertion) reused by drills and regressions.
- **中文**：可执行的验收样本（前置/动作/断言），供 drill 与回归复用。
- **Source**：`01_核心协议.md` · 关键词「用例」

### determinism · 确定性

- **EN**：Deterministic derivation: output is a pure function of input and rules, idempotent and byte-comparable.
- **中文**：确定性派生：输出是输入与规则的纯函数，幂等且逐字节可比。
- **Source**：`01_核心协议.md` · §1.1 模块头机读契约（v1.0.0 C1 · T1-1） · 关键词「确定性」

### defect injection · 缺陷注入

- **EN**：Deliberately injecting known defects to prove the criteria bite (they go red, and only where they should).
- **中文**：故意注入已知缺陷以验证判据有咬合（能红、且只红该红处）。
- **Source**：`scripts/gate_defect_bench.py` · 关键词「缺陷注入」

### gate · 门

- **EN**：The single quality gate before output (e.g. M80): the structural gate hard-blocks, the quality gate judges by profile.
- **中文**：输出前唯一的质量闸（M80 等）：结构门硬阻断，质量门按 profile 判定。
- **Source**：`02_联动注册表.md` · §2. 官方核心模块表（13 件） · 关键词「输出质检门」

### gatekeeping · 门禁

- **EN**：Persistent checks that turn protocol clauses into executable criteria (verify checkN); failures block release.
- **中文**：把协议条款做成可执行判据的常驻检查（verify checkN）；失败即阻断发布。
- **Source**：`protocol/CONFORMANCE.md` · 关键词「门禁」

## 证据层

### receipt · 回执

- **EN**：A verifiable proof of inclusion (this entry ∈ the full set) with leaf digests bound to content.
- **中文**：带 inclusion proof 的可验证证明（某条 ∈ 全量），叶摘要绑定内容。
- **Source**：`protocol/CONFORMANCE.md` · 关键词「回执」

### canonical form · 规范形

- **EN**：The single deterministic textual form (key order, whitespace and newlines normalized); anything else is reported as non-canonical and canonicalized.
- **中文**：唯一的确定性书写形式（键序/空白/换行归一）；规范形外一律以 canonical 输出为准。
- **Source**：`desktop/src/core/content_ir.py` · 关键词「规范形」

### evidence · 证据

- **EN**：Machine-checkable facts (digests, receipts, execution records, audits), not self-claims.
- **中文**：可机核验的事实（摘要/回执/执行记录/审计），不是自述。
- **Source**：`01_核心协议.md` · §1.2 Conformance 一致性分级（43 A2） · 关键词「证据」

### evidence chain · 证据链

- **EN**：A traceable chain from source of truth to artifact (digest binding, receipt inclusion proof, audit sign-off).
- **中文**：从真源到产物的可回溯链条（摘要绑定 + 回执包含证明 + 审计签收）。
- **Source**：`desktop/src/core/domain_pack.py` · 关键词「证据链」
