# DEEP_DIVE · NF 心智模型（给 AI 的深刻理解层）

> 最后更新：2026-11-12
> 位置：AI 入口链的**理解层**——只为懂 NF 为什么这样设计；操作路径见 `docs/agent/AGENT_START.md` → `docs/agent/AI_ROUTING.md` → `docs/agent/agent_组装指令包_v0.2.md`。
> 读法：先 §1–§5 建模型，再用 §7 十问自检；答不出来回对应小节。

## §1 本质：内容契约层，不是叙事生成器

一句话：NF 定义「AI 稳定产出长内容」的协议、质量与资产标准——**定内容，不定模型**。叙事只是官方第一个域包（P02 校园情感 / P03 西幻生存最成熟），协议本体域中立。

不是什么：不是模型、不是提示词模板集、不是某厂商 SDK、也不是 MCP 专属（MCP 只是可对接的连接协议之一）。

三层心智模型：

| 层 | 承载什么 | 真源 |
|---|---|---|
| 协议层 | 结构、契约、注册表、执行协议——所有零件长什么样 | `01_核心协议.md` 至 `07_官方核心出厂与社区预设导航.md` |
| 资产层 | 数据 / 知识本体；资产键经五接口访问，模块不直读散文件 | `05_资产库/`、`community/` |
| 执行层 | 让协议可装载、可质检、可复现 | `desktop/src/core/`、`scripts/nf.py` |

> 与抽象阶梯的关系：`protocol/LAYERS.json` 把同一系统切成四阶（契约 → 资产 → 引擎 → 出口）；三层回答「谁是什么」，四阶回答「依赖往哪走」，两者不冲突。

**三正交分离（I1，01 §5）**：模块 = 能做什么、管线 = 以什么顺序做、资产 = 在什么世界做；三者彼此独立，任意一方整体替换不影响另外两方。其余四条不变式：I2 核心固定 / I3 通信契约 / I4 数据隔离 / I5 真相唯一。

## §2 质量观：单变量 + 五维纵深

决策函数只有一个变量：**质量**。使用量、star、影响力不算目标，也不进立项与排期（口径见 `STRATEGY.md` §二）。

五维纵深（人读复跑说明见 `docs/verification-cards.md`）：

1. **静态可核验**——门禁全绿是底线，不是顶尖；
2. **动态可执行**——协议被 AI 真实执行时的保真（纵深主战场）；
3. **架构纯度**——零私货、零冗余、分层清晰；
4. **资产密度**——资产语义厚度与键质量；
5. **文档可执行性**——照读能执行，不是参考资料。

内部法官链：`verify → audit → drill → 真实战例`；外部只作机制借鉴，不作质量背书。**门禁绿 ≠ 质量顶尖。**

## §4 运行心智：读 → 判 → 配 → 装 → 执 → 验

| 步 | 做什么 | 入口 / 验收 |
|---|---|---|
| 读 | 读入口与协议 | `docs/agent/AGENT_START.md` → `docs/agent/agent_组装指令包_v0.2.md` |
| 判 | 判需求（预设 / 自定义 / 单件） | `nf assemble "<需求>"` 澄清回填；拿不准读 `07_官方核心出厂与社区预设导航.md` |
| 配 | 配模块 / 管线 / 资产 | `02_联动注册表.md`（唯一真相）+ `03_管线库/`、`04_模块库/`、`05_资产库/` |
| 装 | 装成完整版 | 指令包八段骨架 + `nf assemble "<需求>" --build --dest <目录>` |
| 执 | 运行时装载 | `06_Agent执行协议.md`；带 `world_model` 的调度模块用 `nf worldmodel --run` 验状态相位图与轨迹 |
| 验 | 验收 | `nf assemble "<需求>" --check <out.md>` + `bash verify.sh` + drill |

每一步都要引用真实件，禁止凭记忆（零编造）。

## §5 纪律红线

- **零编造**：编号 / 资产键 / 依赖拿不准就留空并标注。
- **计划不外发**：计划 / 草案留本地；公开仓只放结果、状态、正式协议与代码（见 `STRATEGY.md` §四）。
- **引用不等于背书**：外部项目 / 工具是候选建议，不是 NF 承诺。
- **门禁绿 ≠ 顶尖**：静态可核只是底线，动态可执行才算纵深。
