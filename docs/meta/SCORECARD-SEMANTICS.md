# 评分语义澄清（MT-04）

## 结论

OpenSSF Scorecard（及任何同类「过程评分」）衡量的是**过程与卫生**：

- 仓库配置是否最小权限、依赖是否锁定、是否有分支保护、是否有安全策略文件、是否使用危险工作流；
- 发布与构建是否可追溯。

它**不衡量**功能正确性、**不衡量**「没有 Bug」、**不衡量**协议是否自洽或内容质量高低。
把分数当成质量证明、或去掉限定语对外宣传，属于夸大。

## 对外引用规则

1. 引用分数时必须带限定语：「Scorecard 衡量过程与卫生，不衡量功能正确性」。
2. 不得用分数替代 `verify.sh` 的 PASS/FAIL 结论。
3. 若某个低分项是单人仓库的结构性事实（如 Code-Review 无第二评审者），如实说明而不是刷分。
