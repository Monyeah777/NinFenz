## 解决什么

认知核此前只有两个门禁：行话术语表（`glossary`）与执行分档（`runbook/playbook`）。
它们管**用词与执行形态**，不管「怎么钻一个问题」。结果是「深入钻研」不可复现：
同一个问题换个时间、换个会话，切片不同、检索词不同、结论强度也不同。

这层只做**计划**、不做结论：

| 产出 | 是什么 |
|---|---|
| 切片（slices） | 固定 7 个面：定义/机制/证据/边界/对比/量级/落地；depth 决定取几个（1→3、2→5、3→7） |
| 检索词（terms） | 每片给中/英/操作三类检索词（可直接喂 web 搜索，也可喂仓内 `rg`） |
| 方法论路径（paths） | 从方法库取方法，按序给出「怎么钻」：步骤 / 产出 / 证伪条件 |
| 证据台账（ledger） | 每条主张必须落一行：来源 + 强度（实测/一手条款/一手代码/推测/未证）+ 证伪条件 |

## 方法库（怎么钻）

| id | 方法 | 何时用 |
|---|---|---|
| M1 | 第一性原理：拆到不可再分的约束 | 概念新、说法多、来源互相矛盾 |
| M2 | 机制对比：同问题至少三种实现 | 要选型，或怀疑「只有一条路」 |
| M3 | 证据溯源：每条断言指到一手来源 | 任何要写进结论的断言 |
| M4 | 边界与反例：先写它会怎么失效 | 带「保证/抗/防/不可」字样的主张 |
| M5 | 量化与度量：把主张换成指标 | 性能/可靠性/成本/覆盖率 |
| M6 | 溯因排障：现象 → 候选根因 → 区分性实验 | 故障/异常/回归 |
| M7 | 对抗审阅：扮评审逐条找漏洞 | 结论要对外/要负责任 |
| M8 | 决策收口：建议 + 触发条件 + 回滚 | 研究要落到行动 |

每条方法都带 `steps`（≥2 步）、`output`、**`falsifier`（证伪条件）**——
没有证伪条件的方法不许入册（判据见 `test_cognition_plan.py`）。

## 用法

```bash
nf cognition --list-methods                      # 看方法库
nf cognition --plan "水印抗转码" --depth 2        # 出计划（标准 5 片）
nf cognition --plan "水印抗转码" --depth 3 --json --out plan.json
nf cognition --plan "watermark transcoding" --methods M3,M4   # 只用指定方法
```

## 判据（可证）

```bash
python -m unittest desktop.tests.test_cognition_plan    # 16 项
```

- 结构齐：每片有问题 / 中英检索词 / 操作方法 / 证据欠账 / 证伪条件；
- 方法论真：引用的方法必须在库里，路径覆盖所有被用方法，order 连续；
- 深度可调且**确定性**：同输入两次输出逐字节一致；
- 不编造：纯 CJK 主题的英文检索词标 `en_needs_human=true`（不假装有译名），
  英文主题才派生英文词。

## 边界（不承诺）

- 这层给的是**计划**：切片与检索词是模板化展开，不保证覆盖该主题的全部专业面；
- 不做检索、不做判断、不产生结论——结论必须回填 ledger 且 `strength≠未证`；
- 方法库是数据不是真理：新增方法 = 加一条数据（含 falsifier），不改代码。
