## 一、先自测：你属于哪一档

按序回答，**答「能」须有证据**：

| # | 自测问题 | 能 → | 不能 → |
|---|---|---|---|
| 1 | 你能 clone 仓库，或执行 shell / Python 并看到退出码？ | A 线 | 问 2 |
| 2 | 你能打开 raw 直链并读到正文（不是 404 / 登录墙）？ | B1 线 | B2 线 |
| 3 | 你只能读使用者粘贴的文本？ | B2 线（已免除，自取冻结卡） | — |

判定证据规则：**不能靠「我应该可以」自判**——A 线必须真跑通一条只读命令（下方 §二 的验收列）；B1 必须真读到一件 raw 正文（如 `01_核心协议.md` 的 raw 直链）；拿不出证据就按下一档处理，并在交付里写明「档位 + 证据」。
