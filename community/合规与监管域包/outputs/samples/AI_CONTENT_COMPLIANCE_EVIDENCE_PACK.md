## 2. AI 披露与标识

- 披露对象、方式与文本见下表；标识分显式标识与隐式标识两类，逐类登记位置与内容。

| 披露对象 | 披露方式 | 披露文本 |
|---|---|---|
| 终端读者 | 内容首屏可见声明 | 本内容由人工智能生成，经人工复核后发布。 |
| 交互用户 | 对话入口一次性告知 | 你正在与 AI 系统交互，回复由 AI 生成。 |

| 标识类型 | 标识位置 | 标识内容 |
|---|---|---|
| 显式标识 | 内容首屏与图片角标 | 人工智能生成文字提示 |
| 显式标识 | 分享卡片 | 同文案 + 生成服务提供者名称 |
| 隐式标识 | 文件元数据 | 生成合成属性 + 服务提供者编码 + trace_id |

- 深度合成内容（人脸替换、声音克隆）另加显式声明：由人工智能生成或操纵。
- 披露粒度与格式参照 2026-06 透明度行为准则；标识方法依据 GB 45438-2025。

## 3. 数据来源与授权

| 数据来源 | 授权方式 | 用途 |
|---|---|---|
| 自有语料（营销文案库） | 内部授权（组织所有） | 生成文案的检索底料 |
| 公开许可数据集（demo-1.2） | CC BY 4.0 许可 | 生成样例与评测 |
| 客户提交材料 | 客户书面同意（合同附件 C-2026-07） | 仅为该客户生成内容 |

- 每条来源均有授权或可查证的许可凭证编号（见索引 `EVIDENCE_PACK_INDEX` 行 4）；无授权来源不得入包。
- 数据出处按本表登记；跨用途复用须重新登记授权。

## 4. 风险分级与人类监督

| 风险等级 | 风险描述 | 处置措施 |
|---|---|---|
| 高风险 | 生成内容涉及医疗建议，可能影响用户决策 | 人工复核前置；逐条留审计日志 |
| 有限风险 | 营销文案可能夸大产品能力 | 显式标识 + 人工复核后发布 |
| 最小风险 | 内部会议摘要，不对外 | 抽样复核；到期删除 |

- 档位只用不可接受风险、高风险、有限风险、最小风险四档，不自造其他档位。

| 监督角色 | 监督动作 | 触发条件 |
|---|---|---|
| 内容负责人 | 人工复核生成内容的事实与口径 | 每次对外发布前 |
| 合规联系人 | 人工确认披露与标识齐备 | 新内容类型首次上线 |
| 平台负责人 | 审批高风险条目的上线与例外 | 风险登记表出现高风险 |

## 5. 审计日志与保留期

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| trace_id | string | 是 | 链路标识，贯穿披露与复核 |
| event_time | string | 是 | ISO 8601 时间戳（含时区） |
| event_type | enum | 是 | generate/review/publish/retract/delete |
| actor_id | string | 是 | 去标识化操作者 ID |
| content_ref | string | 是 | 内容编号或摘要 |
| decision | enum | 是 | pass/block/escalate |

- 日志只追加；更正以 retract 或 delete 事件表达，不原地改历史。

| 证据类型 | 保留期 | 到期处置 |
|---|---|---|
| 审计日志 | 保留期 3 年 | 到期批量删除并留 delete 事件 |
| 披露记录 | 保留期 2 年 | 内容下线后到期删除 |
| 授权凭证 | 保留期 5 年 | 授权终止后封存，到期销毁 |

- 联系人：合规联系人 compliance@example.org（响应 1 个工作日）；数据保护官 dpo@example.org。
