# 资产键 TECH_TEMPLATE_SAFETY · 安全章节模板

> 资产键：`TECH_TEMPLATE_SAFETY`｜归属：技术文档域包（P06）｜对应 doc_type：`safety`｜消费方：M90 结构装配（按 doc_type 取章节骨架）、M97 术语管理（术语一致性）。
> 依据：GB/T 19678.1-2018 安全信息分级（危险/警告/注意）＋ Microsoft Style Guide（祈使句、单空格、缩写首用定义）。

## 1. 适用场景

设备首次通电前的用电/机械/化学/静电风险告知；适用于所有含高压、运动部件或静电敏感器件的设备。

## 2. 章节骨架（默认标题，可按产品微调但不改语义）

1. 安全须知（概述本设备的风险分类与阅读对象）
2. 危险等级说明（危险/警告/注意三级，逐级给后果与规避动作）
3. 用电安全（电源规格、接地要求、断电操作）
4. 机械与搬运安全（重量、吊点、防倾倒）
5. 静电防护（ESD 腕带、接地台面、包装要求）
6. 环境与化学安全（温湿度、腐蚀性气体、电池处置）
7. 应急处理（触电、起火、泄漏的停机与上报路径）

## 3. 必填条目

- 每级警示必须成对出现「信号词 + 后果 + 规避动作」，禁止只写「注意安全」。
- 必须给电源参数（电压/频率/最大电流）与接地方式；参数值与「规格」章节一致。
- 必须给应急处置的上报入口（内部工单号/电话占位由产品方回填，不得留 TODO）。
- 必须覆盖 ESD 防护（若设备含电子器件）；术语用「ESD」，不用「静电」作规范词。

## 4. 质量要点（对应 gate profile 条款）

- 安全信息分级标识 → `GB-19678-SAFETY-01`（警示标签在场）。
- 术语首用定义 → `GB-19678-TERM-01`；正文用规范术语，不混用别名。
- 标题句式/末尾标点/单空格 → `MS-STYLE-HEADING-SENTENCE` / `MS-STYLE-HEADING-PUNCT` / `MS-STYLE-SPACE-01`。
- 结构完整 → `GB-19678-STRUCT-01`（安全章节在场）。

## 5. 写作示例（示意，参数以实际产品为准）

警示：高压危险。断电并等待指示灯熄灭后，再打开机箱。

注意：本设备含静电敏感器件。接触 PCB 前先佩戴 ESD 腕带并可靠接地。

## 6. 与其他模板的衔接

安全章节必须在「安装」之前出现；「操作」章节的风险动作回链本章节对应等级，不重复展开。
