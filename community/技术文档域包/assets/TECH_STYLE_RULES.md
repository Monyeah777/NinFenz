# 资产键 TECH_STYLE_RULES · 技术文档风格规则

> 资产键：`TECH_STYLE_RULES`｜归属：技术文档域包（P06）｜消费方：`gate_profiles/techdoc-strict.json`（S1–S10 逐条落成 clause）、M80 质量门（profile 软门）。
> 依据：Microsoft Style Guide（句式、标点、空格、缩写、措辞）＋ GB/T 19678.1-2018（结构、术语、修订）＋ DITA 1.3（topic 标题/引用）。规则只收**可机器核验**的部分，文风裁量不入门。

## 2. 编号与层级

- 章节编号用「## N. 标题」单级数字，步骤编号用「1. 2. 3.」有序列表；不混用多种编号体例。
- 层级不得跳级（H1 → H2 → H3），最深 4 级；更深的层级拆分为独立文档。
- 编号一旦发布不复用：删除的章节号留空并记入修订记录。

## 3. 用语与语态

- 祈使句给动作（「断开电源」「测量接地电阻」），不写「用户应该……」这类转述。
- 主动语态优先；被动语态只在动作执行者无关时使用。
- 一个句子一个动作；条件与结果分开写（「若……，则……」）。
- 数值与单位之间单空格；范围用「至」或「~」全篇统一；百分比、温度、力矩给单位。

## 4. 安全信息写法

- 三级信号词：危险（可能致命）＞ 警告（可能重伤）＞ 注意（可能轻伤/设备损坏）。
- 每条警示三件套：信号词 + 后果 + 规避动作；缺一件即不合规。
- 警示放在风险动作**之前**，不放在章节末尾。

## 5. 术语与引用

- 术语以 `TECH_GLOSSARY` 为准；别名只作检索，正文一律规范术语。
- 引用外部标准给编号与年份（如 GB/T 19678.1-2018、DITA 1.3）；引用内部章节给可寻址锚。
- 缩写表与术语表分离：缩写进术语表「缩写类」条目，不另立第二份表。

## 6. 与模板的关系

六类章节模板（`TECH_TEMPLATE_SAFETY` / `TECH_TEMPLATE_UNBOXING` / `TECH_TEMPLATE_INSTALLATION` / `TECH_TEMPLATE_OPERATION` / `TECH_TEMPLATE_TROUBLESHOOTING` / `TECH_TEMPLATE_SPECIFICATION`）规定结构与本文件规定的风格叠加使用：模板管「写什么」，本文件管「怎么写」。
