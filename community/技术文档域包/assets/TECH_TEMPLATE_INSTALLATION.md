# 资产键 TECH_TEMPLATE_INSTALLATION · 安装章节模板

> 资产键：`TECH_TEMPLATE_INSTALLATION`｜归属：技术文档域包（P06）｜对应 doc_type：`installation`｜消费方：M90 结构装配、M97 术语管理、M98 修订记录。
> 依据：GB/T 19678.1-2018 安装与调试信息＋ Microsoft Style Guide（步骤编号、祈使句、单位与数值写法）。

## 1. 适用场景

设备就位、上电、网络接入与初始配置；面向具备基础电气/网络常识的安装人员。

## 2. 章节骨架

1. 安装条件（空间、承重、环境温湿度、供电与接地）
2. 工具与物料清单（工具名 | 规格 | 用途三列表格）
3. 机械安装（就位、固定、防倾倒）
4. 电气连接（电源线、接地线、线序与力矩）
5. 网络与信号接入（接口类型、线缆规格、地址规划）
6. 上电与初始配置（上电顺序、指示灯判读、首次登录）
7. 安装验收（逐项打勾的验收清单表）

## 3. 必填条目

- 安装步骤必须为有序列表，一步一个动作，命令与参数给确定值（含单位）。
- 必须给接地电阻、线缆规格与最大线缆长度等可测参数，并与「规格」章节一致。
- 上电顺序与断电顺序分别给出；涉及高压的操作回链「安全」章节等级。
- 验收清单必须是表格（检查项 | 判据 | 结果），判据可观测（灯态/读数/连通性）。

## 4. 质量要点（对应 gate profile 条款）

- 操作步骤有序列表 → `DITA-1.3-TASK-STEPS-01`（安装/操作按任务型 topic 组织）。
- 文档类型声明 → `DITA-1.3-DOCTYPE-01`（doc_type=installation 在白名单）。
- 标题层级不跳级 → `GB-19678-HIER-01`；表格列数一致 → `MS-STYLE-TABLE-01`。
- 缩写（API/PCB/ESD）首用定义或词表放行 → `MS-STYLE-ABBR-01`；术语一致性 → `GB-19678-TERM-02`。

## 5. 写作示例（示意）

1. 将设备就位于水平台面，四周预留 100 mm 散热空间。
2. 连接保护接地，测量接地电阻，读数不大于 4 Ω。

## 6. 与其他模板的衔接

安装验收通过后进入「操作」章节；安装中发现的硬件异常转「故障」章节，不在安装步骤内展开排障。
