# 资产键 TECH_TEMPLATE_TROUBLESHOOTING · 故障章节模板

> 资产键：`TECH_TEMPLATE_TROUBLESHOOTING`｜归属：技术文档域包（P06）｜对应 doc_type：`troubleshooting`｜消费方：M90 结构装配、M97 术语管理、M98 修订记录（故障条目与已知问题库联动）。
> 依据：GB/T 19678.1-2018 故障与维护信息＋ Microsoft Style Guide（症状/原因/处置三段式、条件句、可观测判据）。

## 1. 适用场景

设备或软件出现异常时的分级排障；读者按「先看症状、再查原因、最后执行处置」的顺序使用。

## 2. 章节骨架

1. 排障前须知（安全前置、可恢复与不可恢复故障的界限、需联系售后的条件）
2. 症状索引（症状 | 可能原因 | 处置入口三列表格，按严重度排序）
3. 分级排障步骤（按症状逐条展开：观察项→判定阈值→动作）
4. 日志与诊断（日志位置、关键字段、自检命令）
5. 备件更换（可换件清单 | 更换步骤 | 复位校验）
6. 升级路径与上报（RMA 申请、升级时限、需提供的证据）

## 3. 必填条目

- 症状必须可观察（灯态、报错码、读数、日志字段），不写「机器坏了」。
- 每条处置必须给「执行动作」与「成功判据」；动作涉及带电/高温时回链「安全」章节等级。
- 需返修的条目必须给 RMA 申请方式与需附证据（序列号、日志、现场照片）。
- 已知原因未确认时如实写「待定位」并给隔离措施，不得用「可能是 XX」充当结论。

## 4. 质量要点（对应 gate profile 条款）

- 症状表列数一致 → `MS-STYLE-TABLE-01`；表格公式化呈现 → `GB-19678-REVISION-02` 同族表格判据。
- 术语首用与一致性（RMA/MTBF/固件）→ `GB-19678-TERM-01` / `GB-19678-TERM-02`。
- 标题句式与末尾标点 → `MS-STYLE-HEADING-SENTENCE` / `MS-STYLE-HEADING-PUNCT`。
- 文档结构完整（故障章节在场）→ `GB-19678-STRUCT-01`。

## 5. 写作示例（示意）

症状：面板红色指示灯常亮且自检报 E03。

判定：断电重启后 30 s 内仍报 E03，判定为传感器回路异常，进入「备件更换」。

## 6. 与其他模板的衔接

故障处置可能要求重新安装/校准，此时回到「安装」章节对应步骤；每次新增故障条目须在「修订记录」登记并在已知问题库同步。
