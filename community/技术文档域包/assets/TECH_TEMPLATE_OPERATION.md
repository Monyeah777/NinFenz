# 资产键 TECH_TEMPLATE_OPERATION · 操作章节模板

> 资产键：`TECH_TEMPLATE_OPERATION`｜归属：技术文档域包（P06）｜对应 doc_type：`operation`｜消费方：M90 结构装配、M97 术语管理（操作类术语首用定义）、M98 修订记录（操作流程变更入库）。
> 依据：GB/T 19678.1-2018 使用信息＋ Microsoft Style Guide（祈使句、主动语态、单空格、弱表达禁用）。

## 1. 适用场景

日常启停、参数设置、模式切换与例行检查；操作对象是设备与配套软件界面。

## 2. 章节骨架

1. 操作前确认（权限、环境、物料与安全前置）
2. 启动与停止（分步编号，含正常与紧急停止两条路径）
3. 参数设置（参数名 | 取值 | 单位 | 说明四列表格）
4. 模式与流程切换（切换条件与生效时机）
5. 例行检查（检查项 | 周期 | 判据三列表格）
6. 记录与交接（操作记录字段、异常上报）

## 3. 必填条目

- 启停与切换步骤必须为有序列表；每步只含一个可执行动作。
- 参数表必须给取值范围与单位；危险动作回链「安全」章节等级。
- 例行检查判据必须可观测（读数范围/灯态/日志字段），不写「运行正常」。
- 正文用确定说法：给判定条件与阈值，不用「大概」「可能」「尽量」等弱表达。

## 4. 质量要点（对应 gate profile 条款）

- 操作章节含有序步骤 → `DITA-1.3-TASK-STEPS-01`；章节非空 → `DITA-1.3-SHORTDESC-01`（每节有简摘/导语）。
- 弱表达 → `MS-STYLE-WEAK-01`；单空格与标点 → `MS-STYLE-SPACE-01`。
- 术语别名混用 → `GB-19678-TERM-02`；修订可追溯 → `GB-19678-REVISION-01`。

## 5. 写作示例（示意）

1. 确认设备处于停止状态且面板无报警后，再切换运行模式。
2. 将目标温度设为 25 ℃，等待读数稳定在 ±1 ℃ 后进入下一步。

## 6. 与其他模板的衔接

操作中出现的可恢复异常按「故障」章节的「症状—原因—处置」表处理；流程性变更须登记「修订记录」。
