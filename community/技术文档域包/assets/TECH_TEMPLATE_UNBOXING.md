# 资产键 TECH_TEMPLATE_UNBOXING · 开箱章节模板

> 资产键：`TECH_TEMPLATE_UNBOXING`｜归属：技术文档域包（P06）｜对应 doc_type：`unboxing`｜消费方：M90 结构装配、M98 修订记录（随机附件清单变更入库）。
> 依据：GB/T 19678.1-2018 交付与验收信息＋ Microsoft Style Guide（清单格式一致、缩写首用定义）。

## 1. 适用场景

到货验收与首次开箱：核对包装、随机附件、外观损伤，并记录缺件/破损以便走 RMA 流程。

## 2. 章节骨架

1. 到货检查（外包装外观、封装、受潮/跌落痕迹）
2. 开箱步骤（剪开封装、取出缓冲材、依序取件，禁止拉拽线缆）
3. 随机附件清单（附件名/数量/用途三列表格）
4. 主机与配件外观检查（划伤、变形、接口异物）
5. 缺件与破损处理（保留证据、拒收或登记 RMA）
6. 首次通电前确认（对照「安全」与「安装」章节）

## 3. 必填条目

- 随机附件清单必须是表格（附件名称 | 数量 | 用途/备注），数量为确定整数，不写「若干」。
- 必须写明缺件/破损的取证要求（外包装照片、序列号、到货日期）与登记入口。
- 必须引用「安全」章节的 ESD 要求后再触碰器件；开箱环境要求（温湿度/台面）明确。
- 涉及返修的下一步须给 RMA 编号申请方式，不直接写「联系售后」了事。

## 4. 质量要点（对应 gate profile 条款）

- 清单表格列数一致 → `MS-STYLE-TABLE-01`；附件清单表在场 → `GB-19678-STRUCT-01`（结构与模板一致）。
- 列表标记后单空格 → `MS-STYLE-LIST-01`；标题句式与末尾标点 → `MS-STYLE-HEADING-SENTENCE` / `MS-STYLE-HEADING-PUNCT`。
- 术语首用定义 → `GB-19678-TERM-01`（开箱/RMA/ESD 首次出现须已定义）。

## 5. 写作示例（示意）

1. 检查外包装有无破损或受潮痕迹；异常时拍照留存并拒绝签收。
2. 沿封装标识剪开，取出全部缓冲材后逐件取出设备与附件。

## 6. 与其他模板的衔接

开箱结束以「首次通电前确认」收口，随后进入「安装」章节；缺件处理走 RMA，不进入安装步骤。
