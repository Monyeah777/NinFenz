## 背景

此前（已随本次迁移移入私有仓的）`ADR-0007` 的裁决是「decisions/ 留在产品仓（作为 decisions.py 的数据真源）」。
2026-10-25 作者裁决更新：**任何暴露决策意图都不安全**——决策记录、交接、复盘属于内部材料，
不应出现在公开仓库，也不应随 npm 发布物分发。

本条自身也是可核验的 meta 决策：`status: accepted` 已由协议回执锚定（`protocol/RECEIPTS.json`）；
真实件归档面 = 私有 Plan 仓 `governance/decisions-archive/`；公开面保留「模板 + ERRATA 勘误 + INDEX 投影」
是因为模板可复用、勘误只改引用指针（ADR 正文逐字节不变以免回执锚定失效）、索引可公开读。

## 决策

1. 真实 ADR / 交接件 / 复盘件迁至**私有 Plan 仓**归档（`governance/decisions-archive/`）；
2. 公开仓三目录只保留：README（政策说明）、格式模板（`ADR-9xxx` / `HO-9xxx` / `PO-9xxx`）、
   `ERRATA.json` 与 `INDEX.md` 投影；
3. 发布面（npm payload）**默认拒绝**这三目录的内容——`packaging/npm/tools/payload-policy.mjs` 的
   `INTERNAL_DIRS` 明列 `decisions/` / `handovers/` / `postmortems/`（同类内部件 `changes/` 一并拒绝）；
4. 新增判据 `test_publish_boundary.py`：公开仓三目录出现非白名单件即 FAIL。

本裁决沿用两条既有原则：**门禁不注水**（判据不因迁移而放宽）与**单一真源**（模板与政策只在本目录一处）。

## 后果

好处：公开面与发布物不再暴露决策意图；`nf decisions/handover/postmortem` 功能仍可用
（目录与模板在场，真实档案按需放本地/私有仓）。
代价：真实决策的「仓内可追溯」改为「私有仓可追溯」；`nf decisions show` 在公开克隆里只看到模板。
若将来要恢复公开，须新开 ADR 取代本条，而不是就地删判据。

可核验面（本决策的判据落点）：

- 目录白名单 = `desktop/tests/test_publish_boundary.py`（decisions/ handovers/ postmortems/ 三目录正则，出现非白名单件即 FAIL）；
- 决策层语义 = check33 新面汇总门禁（决策层面）+ `desktop/tests/test_decisions.py`（ID/文件名一致、必填段、证据可解析、accepted 须回执锚定、INDEX 投影漂移即 FAIL）；
- ERRATA 只登记引用指针类勘误、不碰 ADR 正文（`decisions/ERRATA.json`，schema nf-decisions-errata/1）；
- INDEX 投影 = `nf decisions reindex` 从各 ADR frontmatter 重建（勿手改）。
