# 模块 M50 · 调度器

> 类别：通用｜来源：核心｜挂载点：调度器（全局）｜依赖：M00｜被依赖：M80｜发布：intent_received

```yaml
machine_contract:
  conformance: "L2"
  schema: "1"
  id: M50
  name: 调度器
  category: 通用
  layer: 调度器
  inputs: [M00]
  outputs: [intent_id, mode, text]
  events:
    publish: [intent_received]
    subscribe: []
  interfaces: []
  world_model:
    abstract_state:
      variables:
        - name: pipeline
          kind: string
          source: M50
          slot: data_bus.active_pipeline
          note: 当前装配管线 id
        - name: tick
          kind: integer
          source: 通用:M10
          slot: WorldState.time.tick
          note: 时间节拍；M50 只读
        - name: phase
          kind: string
          source: M50
          slot: data_bus.round.phase
          note: 主循环抽象相位
        - name: phase_trace
          kind: array
          item_kind: string
          source: M50
          slot: data_bus.round.phase_trace
          note: 主循环相位轨迹；旧相位按迁移顺序追加
      initial:
        pipeline: P01
        tick: 0
        phase: begin
        phase_trace: []
    transition:
      initial_phase: begin
      phases:
        - phase: begin
          next: run
          guard: 回合开始并快照 M00 数据槽
          writes: []
        - phase: run
          next: end
          guard: 按 02 §6 执行官方核心与域包合并顺序
          writes: [PlayerState.memories.working]
        - phase: end
          next: archive
          guard: I2 核心固定结构/字段一致性校验通过
          writes: []
        - phase: archive
          next: roll
          guard: end 通过后执行回合末状态写回
          writes: [PlayerState.memories.episodic, PlayerState.memories.semantic]
        - phase: roll
          next: begin
          guard: 回卷至 begin 快照并进入下一回合
          writes: [PlayerState.memories.working]
    invariants:
      - "抽象状态变量必须是 world_model.abstract_state 显式声明的有限集"
      - "tick 单调不减"
      - "phase 只在 begin/run/end/archive/roll 有限集合内迁移"
      - "每个 phase 显式声明 next，迁移图从 initial_phase 全可达"
      - "非 M50 模块不得直写 M00 数据槽"
    checks:
      - kind: finite_phase
        field: phase
        values: [begin, run, end, archive, roll]
      - kind: monotonic
        field: tick
      - kind: finite_sequence
        field: phase_trace
        values: [begin, run, end, archive, roll]
  io_types:
    outputs:
      intent_id: untyped
      mode: untyped
      text: untyped
    inputs:
      M00: state
```

## 1. 职责

回合调度器。按注册表给出的执行顺序（官方核心装配真相源见 02 §6）依序驱动各层模块；装域包后按包索引动态合并。回合结束回卷并进入下一回合。主循环决定"谁先跑、谁后跑、何时结算"。

本文件三形态：

- 头部引用块 = 速览（类别 / 来源 / 挂载 / 依赖 / 发布）；
- machine_contract 块 = 机读投影（check16 契约仲裁 / check28 IDL 校验读取；含唯一在用的 world_model 抽象世界模型）；
- §2–§6 正文 = 契约全集。

三者零矛盾。**全局调度器约定**：layer 字段写「调度器」而非 Pxx，registry 的 mounts 为空（不参与任何层挂载，02 §6 的 10 步顺序中占第 1/2/10 步）；M50 发布 intent_received，**不属零事件模块**，interfaces 保持 [] 合规。

## 2. 执行顺序

官方装配的执行顺序以 **02_联动注册表.md §6 为唯一真相源（I5）**，本模块不维护静态编号清单，避免双源漂移。装配任域包后，按包索引把域包模块合并进对应层位（R3），生成最终执行顺序。

- 官方核心 10 步顺序（02 §6）：M00 初始化 → M50 调度开始 → P10/P20/P30/P50/P70 各层 → M80 输出门 → M50 回卷；M50 自身占第 1、2、10 步，不入任何层。
- 域包合并只追加到对应层位的 default/allowed（02 §5/§8 登记），M50 不维护第二份顺序清单。

## 3. 调度规则

```yaml
scheduler:
  层间同步: 每一步等待上一步完成（同步串行），保证数据因果
  层内: 该层多模块按注册表 available→active 过滤后执行
  跳过: 模块声明 skip（条件不满足）→ 跳过并记 skip_reason
  异常: 单模块异常不中断整轮；捕获后记 error_log，回合继续
  管线切换: 换用其它管线时同步切换挂载表与执行顺序
```

## 4. 回合生命周期

```yaml
round:
  begin:   快照（M00 数据槽）
  run:     按注册表 §6 顺序执行（官方核心 + 域包动态合并）
  end:     校验一致性（I2 核心固定：结构/字段不漂移）
  archive: 回合末状态写回（writeback 三规则，见下）—— end 通过后执行
  roll:    回卷至 begin 快照

writeback:  # 回合末状态写回（经 M00 数据槽总线，仅 M50 于 archive 步触发）
  working→清理:    # 工作层随回合快照滚动：end 后清空重置本回合临时状态，不跨回合滞留
  episodic→写回:   # 重要条目写回 episodic：命中规则集的条目带 tick 追加
  semantic→沉淀:   # episodic 提炼沉淀 semantic：跨回合稳定的事实精炼为 semantic.facts
  约束:            # 仅写 M00 声明的槽（I4 数据隔离）；消费方只读，
                   # 直写他模块字段 = DATA_SLOT_VIOLATION
```

world_model 口径（01 §1.1 抽象世界模型 · 首战实例）：abstract_state 四变量（pipeline/tick/phase/phase_trace）的 slot 必须在 protocol/world_slots.json 在册；transition 的 writes 写目标同样以该文件在册槽路径为准；checks 三类（finite_phase / monotonic / finite_sequence）由 WorldModelRuntime 确定性重放校验，不训练/不宣称模型优劣。

## 5. 违例与边界

- 禁止任何模块在 step 之外自行触发其他模块逻辑（必须经由注册表订阅/挂载）。
- 死循环防护：单回合执行超时/步数超限 → M50 强制打断并回卷。
- 非 M50 模块不得直写 M00 数据槽（I4×I5）；M50 自身也只写 world_model 声明的槽，不越界改他模块内部字段。

## 6. 事件契约

- 发布 intent_received：接收用户意图并广播，供意图驱动管线订阅（P90 的 M90 订阅）；载荷字段 intent_id / mode / text 的机读登记见 protocol/event_registry.json，本模块不另立第二份形状（I5）。
- 订阅：无（M50 只发布不订阅）。
- 机读投影口径：machine_contract.events 是机读投影，本段是正文事件契约全集；intent_received 载荷字段与 machine_contract.outputs 同集，事件名与字段须在 protocol/event_registry.json 在册（check16 读取本模块机读块做装配仲裁）。
