怎么读

  • layer：form / data / iface / eng / gov，对应标准目录的分层。
  • 可达：最近一次探针 HTTP 200；不可达不等于标准失效，只代表该 URL 当时不可取。
  • bound：协议件对该标准的绑定数量；0 表示当前未绑定。
