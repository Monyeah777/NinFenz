五段判定是什么

判定按标准条款拆成 A–E 五段，每段给出 PASS / WARN / FAIL / NA 和对应证据。

A · 显式标识

文本、界面或文件内是否有可读的“AI 生成 / 生成合成”等声明，位置与表述是否符合要求。

B · 隐式标识字段

元数据中是否写入七字段标识结构、生成方信息与保留字段，键名与取值是否自洽。

C · 安全防护信息

生成方安全防护字段、杂凑绑定与签名材料是否在场，能否与内容对应。

D · 内容绑定

标识与文件内容是否绑定，内容被替换或拼接后是否还能被识别。

E · 备案材料

显式标识样例、隐式标识样本、内容摘要与绑定记录是否足以支撑内部归档或备案说明。

证据与整改

每条判定附证据摘录和整改建议；报告给出可复算命令，便于按同一路径复验。

5 分钟自查清单

  1. 文件类型在支持表内，且未加密、未损坏。
  2. 显式标识：文件或界面中能否读到“AI 生成”类声明。
  3. 隐式字段：元数据里是否有 AIGC / Label 结构与生成方信息。
  4. 内容绑定：记录文件哈希、生成时间与工具版本，便于复算。
  5. 整改留痕：保留修改前后两份文件与命令输出。

支持格式与已知限制

读取的是容器元数据与文本标识，不做视觉或听觉的像素级判定。

格式读取的标识载体已知限制
PNG / JPEG / TIFF / GIF / WebPtEXt / iTXt / zTXt、APP1 XMP、EXIF、XMP 扩展块不做像素判定；多页 TIFF 只读首页。
MP4 / MP3 / WAV / FLACmoov.udta.meta / XMP uuid、ID3v2 TXXX、LIST/INFO、VORBIS_COMMENT只读元数据，不解码画面或音轨，不做感知哈希。
PDFInfo 字典、/Metadata XMP仅支持未加密、常见结构；加密 PDF、对象流（ObjStm）、增量更新不支持；非 ASCII 文本可能乱码。
DOCX / OFD / MarkdowndocProps/custom.xml、CustomDatas、头注释块只检查标识字段，不校验正文事实。
xmind / posm / posf / UOFmetadata.json / meta.json、_meta/meta.xml依赖文件自身结构；结构异常时按无法判定处理。
画面水印、音轨提示、视频内嵌字幕不支持自动读取需人工或 OCR 复核；本服务不出具官方检测结论。

加密、DRM、损坏文件与格式清单以外的容器不接单；预检阶段会先确认是否在范围内。
