用当前生成器重跑一份对比：`python site/tools/make-demo-gif.py --out .rivet/scratch/regen.gif` → **34501 B**，与入库的 **34487 B** **字节不同**（尺寸/帧数/时长一致：804×586 · 4 帧 · 9.2s）。

原因：帧文本来自 `tui/nf.py` 的 `demo_frame()`，TUI 文案此后有演进；**入库这份是改名前的遗留产物**（本目录原文已如实记录）。

处理口径：**这是已登记的债**——要消除只需重跑生成器覆盖 `site/assets/demo.gif`（一条命令），属于**会改变公开视觉**的动作，留给作者决定何时替换；在那之前，本页如实标注「入库图 ≠ 当前生成器输出」。
