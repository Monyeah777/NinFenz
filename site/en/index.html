FAQ

Is Community really open source?

Yes. Core code is AGPL-3.0-only. Closed-source embedding, formal SLA, private deployment support and enterprise procurement use a commercial license.

Does NinFenz replace AI governance tools?

No. It supplies the executable output-contract and evidence layer between governance, agent platforms and CI.

Does it check factual truth?

No. It checks contract conformance. Human review and domain processes retain responsibility for accuracy and suitability.

Can it run privately?

Yes. Core validation and reporting are local-first. Enterprise support is available for private deployment.
