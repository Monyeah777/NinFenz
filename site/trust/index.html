能力边界

NinFenz 提供

  • 确定性契约执行
  • Rule ID 和修复提示
  • 可复现报告和哈希
  • CLI / MCP / Agent / CI 集成
  • 发布供应链证明

NinFenz 不提供

  • 事实真实性和法律意见
  • 通用模型观测或漂移检测
  • 实时 Prompt 攻击拦截
  • SOC 2 / ISO 27001 认证
  • 完整 AI inventory 或 DLP
