能力边界

NinFenz 提供

  • 确定性契约执行
  • Rule ID 和修复提示
  • 可复现报告和哈希
  • CLI / MCP / Agent / CI 集成
  • 发布供应链证明

NinFenz 不提供

  • 事实真实性和法律意见
  • 通用模型观测或漂移检测
  • 实时 Prompt 攻击拦截
  • SOC 2 / ISO 27001 认证
  • 完整 AI inventory 或 DLP

标识体检（Label Check）的服务边界

SLA

确认范围与报价后 48 小时（工作日）交付 PDF 报告与 evidence.json。加急需求在预检时单独确认，不默认承诺。

退款与复检

交付前可全额退款；同一文件含 1 次免费复检。交付后 24 小时内可对判定争议申请复检，确认属判定错误的按原路退款或免单。视觉判定、法律意见、备案结果等范围外事项不适用。

数据删除

文件仅在本机或受控环境处理，交付后 7 天内删除原件与中间文件；不出售数据，表单信息仅用于回复本次咨询。

免责

自查结果，不构成官方认定、法律意见或合规认证，也不对备案结果作出承诺；以适用法律法规、标准文本与监管部门结论为准。

支持格式与已知限制见 标识体检；价格与下单流程同页列出。
