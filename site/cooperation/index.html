商业合作

NinFenz 协议与引擎 MIT、免费；Android 应用源码可见（PolyForm Noncommercial 1.0.0，非商业使用免费、商业使用需授权）。合作只围绕“把你的内容工程落地”，不卖协议本体，不卖“会员版”。

接入

协议接入

把现有内容流程映射到 module / pipeline / asset，建立可复现的装配与门禁。

域包

私有域包

为你的行业词表、检查项、模板与资产建立私有协议包，不公开你的内容资产。

审计

内容工程审计

对现有 AI 产线做结构、可复现性、交付物完整性审计，给出可执行整改清单。

移动

NF Mobile 定制

围绕 Android 端的导入、切片、装配、导出做定制；可签私有分发 APK。

适合谁

  • 需要把 AI 长内容变成稳定交付物的团队。
  • 已有模板/SOP，但缺可验证门禁与资产台账的团队。
  • 需要在离线/内网环境处理内容的团队。

怎么开始

在 GitHub 仓库开一个 issue，标题以 [cooperation] 开头，写清：

  • 你的场景与现有流程
  • 期望交付物（协议包 / 审计 / 移动端）
  • 是否要求离线、私有部署
  • 时间与预算范围（可选）

发起合作 Issue 先下载 NF Mobile

不通过聊天工具索取账号、验证码或支付信息；合作以仓库 issue 与正式合同为准。

不做什么

  • 不卖“协议本体授权”或“会员激活码”。
  • 不承诺“AI 写得好”；门禁只管结构与可复现。
  • 不做内容代写、刷量、规避平台审核。
