直接下载 APK（GitHub Releases）

当前为 pre-release 直装版；若链接失效，到 Releases 找 tag mobile-v0.3.7-preview.1。旧版 0.2.0 已下架。

安装

  1. 下载 APK 后，在文件管理器中打开。
  2. 若系统提示“禁止安装未知应用”，允许当前文件管理器/浏览器安装。
  3. 安装完成，打开 NF Mobile；首次可加载 sample pack。
  4. 不需要登录，不需要联网。图片导入走本机 OCR（模型随包内置）。

从 0.2.0 升级（重要）

0.3.7 使用新的发布签名（旧签名私钥已不可用），不能直接覆盖安装 0.2.0。请按顺序：

  1. 在 0.2.0 里打开项目 → 备份/导出项目包（zip）；
  2. 卸载 0.2.0（注意：卸载会删除应用内项目数据）；
  3. 安装 0.3.7-preview.1，用“导入项目包”恢复。

为什么没有 Play 商店

Google Play 开发者账号需要一次性注册费与身份验证；当前版本不走商店，直接提供 APK。APK 与 AAB 使用同一 upload key 签名；Play 版若日后上架，包名保持不变。

非官方渠道的“破解版 / 会员版 / 网盘加速下载”与本项目无关；只从本页或 GitHub Releases 取件。
