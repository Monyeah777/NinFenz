- **来源声明不可机检**：本表只能核「文件在场 + 像素 + 许可文句」；「无外部素材/无第三方图标库」属作者声明，无法用判据证明。
- **替换流程**：换图标必须**同时**更新两个尺寸，并在本表记来源与许可；只换一个会让目录要求（400×400）与站点图标（512）分叉。
