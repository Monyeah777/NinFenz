# 05_资产库/用户自定义/STYLE_DNA.md · 输出 profile 配置
> 位置：05_资产库/用户自定义/（扩增协议槽，见 05_资产库/README §5）
> 用途：M80 质量门（profile 档）的配置槽——**协议层不内嵌任何固定条目**；profile 一律由用户/域包在此配置。
> 说明：本槽是**域中立机制**；具体 profile（域特色档）由域包自定义——可整体替换为自有条目，未配置时质量门不生效。

## 读法（本文件怎么用、怎么验）

- **这是什么**：M80 质量门的 profile 配置槽 + 域中立示例档——**示例不是协议**，条目可整体替换；本文件只提供规则条目，不含阈值与判定逻辑（判定在 M80 §3 `gate_action`）。
- **三类读者**：消费方（M80）= 渲染前经 `asset_get("STYLE_DNA", id)` 取档（或读 protocol.yaml profile 字段）；作者 = 按 §2 schema 新增条目并 `nf asset add` 建档；验收方 = 核对文件头 `nf-asset` 位与 `provenance.json` 台账（check23）。
- **怎么验**：文件头 key/version/status ↔ `05_资产库/provenance.json` 同键记录（check23 三方）；schema 字段与 `05_资产库/用户自定义/README.md` §2 速览一致；键在 `protocol/asset_keys.json` 在册（scope=user_asset）。
- **引用约定**：正文 `§N` 指本文件章节；资产键写大写 `STYLE_DNA`；条目 ID 用户自定（无固定前缀）。

## 1. 配置机制（三式，任选其一）
| 配置方式 | 位置 | 说明 |
| --- | --- | --- |
| a. 资产键 | 本文件（STYLE_DNA）或域包 assets/ 下的 profile 资产 | 渲染前 asset_get 取档 |
| b. protocol.yaml 字段 | 域包 protocol.yaml | 域包自带 profile 声明 |
| c. 缺省（未配置） | — | 仅过结构门即放行，风格由运行方自担 |

> 三式**任选其一**；同一 profile 不得双源声明（a+b 同时存在即产生歧义）。加载口径以 M80 §2.2 为准（本文件不另立加载顺序，I5）。

## 2. 资产键表
| 资产键 | 文件 | schema | 条目 |
| --- | --- | --- | --- |
| STYLE_DNA | STYLE_DNA.md | {dna_id, name, rule, applies_to} | 用户自定（示例档见 §3） |

- schema 真源 = `05_资产库/用户自定义/README.md` §2 速览（本表为投影）；字段：dna_id（条目 ID）、name（名称）、rule（可判定的一句话规则）、applies_to（适用域/管线列表，'*' = 全域）。
- 条目 ID 无固定前缀（用户自定）；新增条目须走 `nf asset add`（asset_register 语义），不改官方命名空间。

## 3. 示例档（域中立，可整体替换）
> 说明：以下为通用示例，用来演示字段形状；**这是示例不是协议**——任何用户/域包可整体替换为自有条目（域特色档随域包提供）；未配置时质量门不生效。
| dna_id | 名称 | 规则（一句话） | applies_to |
| --- | --- | --- | --- |
| P1 | 结构优先 | 保证结构完整、编号合法、引用可寻址 | ['*'] |
| P2 | 术语一致 | 全文同词同义，首现术语登记 | ['*'] |
| P3 | 受众适配 | 按目标读者调整详略与术语密度 | ['*'] |

- 示例条目语义：rule 必须是**可判定**的一句话（可机器/人核验），禁止只写「风格要好」这类无判定标准的词；applies_to 可写域/管线 id 列表（'*' 表示全域）。
- 示例档可整体替换：域特色档由域包提供，本文件示例仅演示字段形状（替换不等于改协议）。
