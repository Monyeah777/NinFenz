# 管线 P01 · 标准管线（官方核心装配）
>
> 官方默认活跃管线。以“装载→语境推进→实体状态→内容生产→决策→装配→一致性→素材→输出”九层线性推进，主循环回卷。
> 实例声明：本管线是通用骨架 **P00**（03_管线库/P00_通用文档生成管线.md）的**官方核心标准装配**——层挂载取 04_模块库 保留的官方核心模块（P40/P60 空层；M50 全局调度、不入 layers；M08 仅 available；M90 属结构装配线）；域模块由社区域包按各自管线装配补充，全部域包以 02 §8 登记为真源。

```yaml
Pipeline:
  id: P01
  name: 标准管线（官方核心装配）
  structure:
    type: linear
    flow:
      - from: P00
        to: P10
      - from: P10
        to: P20
      - from: P20
        to: P30
      - from: P30
        to: P40
      - from: P40
        to: P50
      - from: P50
        to: P60
      - from: P60
        to: P70
      - from: P70
        to: P80
      - from: P80
        to: P00
        condition: =data_bus.round.phase == "roll"
  layers:
    - id: P00
      name: 装载
      description: 初始化数据结构与槽装载；M00 在此建立实体/关系/上下文/队列四类数据槽
      optional: false
      default_modules: [M00]
      allowed_modules: [M00, M20]
    - id: P10
      name: 语境推进
      description: 时间/上下文推进与节拍广播；tick_day 事件广播给订阅方
      optional: false
      default_modules: [通用:M10]
      allowed_modules: [通用:M10, M08]
    - id: P20
      name: 实体状态
      description: 实体状态结算与可见性裁剪：输出只呈现消费方当前可知信息（M23）
      optional: false
      default_modules: [M23]
      allowed_modules: [M23]
    - id: P30
      name: 内容生产
      description: 事件编排、流程状态与实体交互在此生成候选集与交互请求
      optional: false
      default_modules: [事件:M22, M06, M13]
      allowed_modules: [事件:M22, M06, M13, M12]
    - id: P40
      name: 决策
      description: 策略/筛选/规划决策层（决策出口随社区域包装配）；官方核心装配下为空层，候选直通 P50
      optional: true
      default_modules: []
      allowed_modules: []
    - id: P50
      name: 装配
      description: 模板检索供给与交互行为装配（M12 模板检索库）
      optional: false
      default_modules: [M12]
      allowed_modules: [M12]
    - id: P60
      name: 一致性
      description: 跨回合长期状态层（随社区域包装配）；官方核心装配下为空层
      optional: true
      default_modules: []
      allowed_modules: []
    - id: P70
      name: 素材
      description: 知识条目库与组合规则为输出层提供素材与校验
      optional: true
      default_modules: [M20, M24]
      allowed_modules: [M20, M24]
    - id: P80
      name: 输出
      description: 输出质检门按规则渲染文本与状态面板（结构门 + profile 质量门）
      optional: false
      default_modules: [M80]
      allowed_modules: [M80]
  dependencies:
    - from: P20
      to: P30
      reason: M23 可见性裁剪是内容生产的前置信息过滤
    - from: P30
      to: P40
      reason: 候选集是决策输入（P40 为空层时直通 P50）
    - from: P40
      to: P50
      reason: 决策结果驱动装配（P40 为空层时直通 P50）
    - from: P50
      to: P60
      reason: 装配结果写入长期状态（P60 为空层时跳过）
  tags: [官方核心, 标准装配, 线性]
```

## 运行规则

- 每回合由 M50 调度器按注册表 execution_order 依序调度各层默认模块；空层（P40/P60 核心装配下）直接跳过，不阻塞回合。
- optional=true 的层（P40/P60/P70）缺模块时跳过；域模块由社区域包装配后写入对应层。
- 层内模块输出写入数据槽；层间仅通过数据槽与事件通信（I3）。
- 装配社区域包时，域包负责把域模块追加进对应层的 default/allowed，并按域包索引同步注册表 mount_points 与 execution_order。
