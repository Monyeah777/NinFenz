## 真机（OnePlus PLF110 / Android 16）

- 详见 `0.3.7_DEVICE.md`；证据截图 `0.3.7_device_*.png`、旧数据备份 `0.2.0-device-data-20261127.tar`。
- **已修复阻断**：minified/Play 包因 base manifest 残留 MLKit provider 而启动崩溃（`ClassNotFoundException: MlKitInitProvider`）。修复 = base manifest `tools:node="remove"` 两个 MLKit 组件 + feature `dist:fusing include="false"`；release APK、benchmark APK、AAB base manifest 的 `mlkit` 计数均 0。
- 升级链：设备旧 0.2.0（真实 6 项目数据）→ 0.3.7 debug 升级成功，数据保留，冷启动 636ms。
- Play 形态（bundletool local-testing，base + 2 config split、ocr 未装）：冷启动 176–193ms，无崩溃。
- 无障碍：font_scale 200% 布局可用；force_rtl 截图未镜像（OPEN）；TalkBack 未测（OPEN）。
