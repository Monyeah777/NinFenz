## 真机（OnePlus PLF110 / Android 16，2026-11-28）

- 直装 universal APK：`pm install --no-streaming` 成功（该机 OPLUS 安装校验需先 `am force-stop com.oplus.appdetail`，属设备策略，不是 APK 问题）。
- 冷启动 `am start -W` TotalTime：172–205ms。
- 核心链路实测：示例内容导入成功（JNI/JNA op 正常）；图片（jpg/png）导入经 MLKit OCR 成功产出文本（非空、进入预览 1/4 步）。
- 直装包真机验证中发现并修复 3 个 release 阻断：
  1. **JNA keep 规则名错误** → `Native.load` 抛 ClassCastException → 所有核心 op 报 NF-E-005（映射表实证 CoreNativeLib 被改名且方法被裁）；修正后核心恢复。
  2. **MLKit 主线程调用** → 抛 `Must not be called on the main application thread`，被桥兜底误报为「OCR 扩展未安装」；识别改 `Dispatchers.IO`。
  3. **图片 MIME 无入口** → 导入选择器不含 image/*，OCR 能力在侧载/直装形态不可达；补 MIME 并把 4 处调用收敛到 `ImportMime`。
