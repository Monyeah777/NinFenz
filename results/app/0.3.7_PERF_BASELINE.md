## 仪表状态

- `:benchmark` 模块已建立，依赖 benchmark-macro-junit4 1.3.4 / uiautomator 2.3.0 已解析。
- `:benchmark:compileBenchmarkKotlin` 通过；`:app:assembleBenchmark` 通过。
- StartupBenchmark / FrameBenchmark / BaselineProfileBenchmark 已编写。
- 2026-11-27 收口：定位并修复「同进程类遮蔽」第二层——测试 APK 与 app 同进程时，测试代码解析到 app 内被 R8 优化/裁剪过的 kotlin 运行时副本，`Intrinsics.checkNotNullParameter` 抛 NoSuchMethodError。修法：benchmark 变体额外加 `-keep class kotlin.**` 相关 keep（见 `app/android/app/proguard-benchmark.pro`，仅 benchmark 变体，不随 release 发布）；`:app:assembleBenchmark` + `:benchmark:assembleBenchmark` 构建通过，实测 app-benchmark.apk 的 dex 保留 `checkNotNullParameter`。
- 运行入口：`app/scripts/device_macrobenchmark.sh`（装 APK、关三档动画、逐类 `am instrument`、收集原始输出并复原动画）。
- `adb devices` 当前无设备（USB 只有 PLF110 充电态、无 ADB 接口），本轮仍未执行 connectedBenchmark；设备接上后直接跑上面的脚本。
