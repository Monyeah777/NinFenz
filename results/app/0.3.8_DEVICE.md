# NF Mobile 0.3.8-preview.1 真机验收记录（2026-11-28）

## 1. 设备

- 型号：OnePlus PLF110（OP60F9L1），Android 16（SDK 36），serial `3B65AR0183V00000`。
- 工具：`adb`（Android SDK platform-tools）、`apksigner`/`zipalign`（build-tools 36.0.0）、NDK 27.0.12077973。
- 构建链路：`build_core_android.sh`（release core，两 ABI，16KB align）→ `./gradlew :app:assembleRelease`（R8）→ debug key 签名（仅功能验证）。

| 项 | 结果 |

| 安装 | `adb install -r` Success（覆盖 0.3.7-preview.1 数据） |

1. 用 debug 签名 debug 构建写入 `shared_prefs/nf_license.xml`（授权码为 pin 公钥签发的 VECTEST-0001），再覆盖安装同源 release(R8) 构建。

## 6. 说明与边界

- 上传签名 APK **未在设备上覆盖安装**（换签名必须卸载，会清用户数据）；上传签名产物只做 `apksigner verify` + `zipalign -c -P 16 4` + 内容清单静态校验。
- 真机验收使用的是与上传包**同一提交、同一 R8 配置**的 debug 签名同源构建；功能面等价，签名不同。
- 设备 IME 曾在自动化输入时被临时禁用，验证后已恢复（Sogou 输入法已重新启用并设为默认）。
